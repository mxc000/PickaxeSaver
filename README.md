# ⛏️ PickaxeSaver

> **Never lose your pickaxe again.**

**PickaxeSaver** is a lightweight Minecraft mod that protects your pickaxe from breaking at the worst possible moment.

No more watching your favorite pickaxe disappear after mining that last block. ⛏️

---

## ✨ Features

* 🛡️ **Pickaxe Protection**
  Prevents your pickaxe from breaking when its durability reaches its limit.

* ⚡ **Lightweight**
  Designed to do one thing and do it without unnecessary overhead.

* 🎮 **Simple & Seamless**
  No complicated configuration or commands required.

* 🔧 **Easy to Install**
  Drop the mod into your `mods` folder and you're ready to go.

* 💚 **Open Source**
  Fully available on GitHub under the MIT License.

---

## 📦 Installation

### 1. Download

Download the latest release of **PickaxeSaver**.

### 2. Install

Place the downloaded `.jar` file into your Minecraft `mods` folder.

```text
.minecraft/
└── mods/
    └── PickaxeSaver.jar
```

### 3. Launch Minecraft

Start Minecraft with the required mod loader and enjoy your protected pickaxes. ⛏️

---

## 🎯 How It Works

PickaxeSaver monitors your pickaxe while you're mining.

When the pickaxe would normally break, PickaxeSaver prevents the final durability loss from destroying the item.

**Result:**

```text
Normal Minecraft
────────────────────────────
⛏️ ████████████████████
⛏️ ████████████
⛏️ ██████
💥 PICKAXE BROKE

With PickaxeSaver
────────────────────────────
⛏️ ████████████████████
⛏️ ████████████
⛏️ ██████
🛡️ PICKAXE SAVED
```

## 🛠️ Building From Source

Clone the repository:

```bash
git clone https://github.com/mxc000/PickaxeSaver.git
cd PickaxeSaver
```

Build the project using Gradle:

### Linux / macOS

```bash
./gradlew build
```

### Windows

```powershell
.\gradlew.bat build
```

The compiled `.jar` will be available in:

```text
build/libs/
```
